# APMon v1.3.0 — Clearer Betaflight telemetry

## English

- The setup check keeps **Basic readings available** when only the optional Betaflight GPS fix is unconfirmed. It suggests checking the fix source for live GPS without treating it as a prerequisite for the basic readings.
- The Betaflight flight display shows `--` for `GAlt` and GPS speed without a verified fix. A valid `Alt` reading still takes priority, and the sensor list retains the reported `GAlt` and `GSpd` values.
- The dashboard and HUD omit the EKF field in Betaflight. Telemetry diagnostics mark FC status and FC text as **Only with ArduPilot**, using one full-width note on SW.

## Deutsch

- Im Betaflight-Einrichtungscheck bleibt **Basiswerte vorhanden** der Befund, wenn nur der optionale GPS-Fix unbestätigt ist. Der Hinweis zur Fixprüfung bezieht sich auf Live-GPS und stellt die Basiswerte nicht infrage.
- Ohne bestätigten Fix zeigt die Betaflight-Fluganzeige `--` für `GAlt` und GPS-Tempo. Ein gültiger `Alt`-Wert behält Vorrang. Die gemeldeten `GAlt`- und `GSpd`-Werte bleiben in der Sensorliste sichtbar.
- Übersicht und HUD blenden EKF bei Betaflight aus. Die Telemetrie-Diagnose kennzeichnet FC-Status und FC-Text mit **Nur mit ArduPilot**, auf SW in einem gemeinsamen Hinweis über die volle Breite.
