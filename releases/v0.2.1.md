# APMon v0.2.1 — Adaptive color headers and screenshot import

## English

- **Color dashboard and project menu:** Both show **APMon - ArduPilot Telemetry Monitor**
  and the telemetry pulse logo in the same position. The header adapts to font
  metrics to avoid clipping on the TX16S MK3.
- **Telemetry pulse logo on monochrome:** The project menu uses a compact,
  one-color version of the logo. The SW telemetry layout is unchanged from v0.2.0.
- **Screenshot import:** `import_screenshots.py` previews and imports all new
  EdgeTX captures as PNGs. Filenames identify the display, view, language,
  APMon version and capture time. Existing imports are skipped, and the SD
  card is not modified.
- **Hardware and documentation:** The color dashboard and project menu were
  checked on the GX15 and TX15 (480 × 320) and the TX16S MK3 (800 × 480).
  The English and German READMEs share the same structure and use real hardware
  screenshots. These checks are not full hardware qualification.

Use `APMon-SW.zip` for GX12/Boxer or `APMon-COLOR.zip` for GX15/TX15/TX16S MK3.
Back up custom `config.lua` sensor mappings before replacing files on the SD card.

## Deutsch

- **Farb-Dashboard und Projektmenü:** Beide zeigen **APMon - ArduPilot Telemetry Monitor**
  und das Telemetrie-Puls-Logo an derselben Position. Die Kopfzeile passt sich
  der Schriftgröße an, damit der Titel auf der TX16S MK3 nicht abgeschnitten wird.
- **Telemetrie-Puls auf Schwarzweiß:** Das Projektmenü verwendet eine kompakte,
  einfarbige Logo-Variante. Das SW-Telemetrielayout bleibt wie in v0.2.0.
- **Screenshot-Import:** `import_screenshots.py` zeigt eine Vorschau und
  übernimmt alle neuen EdgeTX-Aufnahmen als PNG. Die Dateinamen enthalten
  Displaytyp, Ansicht, Sprache, APMon-Version und Aufnahmezeit.
  Bereits importierte Bilder werden übersprungen; die SD-Karte bleibt unverändert.
- **Hardware und Dokumentation:** Farb-Dashboard und Projektmenü wurden auf
  GX15 und TX15 (480 × 320) sowie TX16S MK3 (800 × 480) geprüft.
  Beide READMEs haben dieselbe Struktur und zeigen echte Senderaufnahmen.
  Die Prüfung entspricht keiner vollständigen Hardwarequalifikation.

`APMon-SW.zip` ist für GX12/Boxer, `APMon-COLOR.zip` für GX15/TX15/TX16S MK3.
Vor dem Austausch der Dateien auf der SD-Karte angepasste Sensorzuordnungen
aus `config.lua` sichern.
