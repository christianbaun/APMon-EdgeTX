# APMon v0.4.0 — Telemetry diagnostics and post-disarm summary

## English

- **Telemetry diagnostics** separates RC link quality, EdgeTX sensor status, FC status packets and the last FC text. The sensor view distinguishes live readings from last known values.
- **Last armed period** shows time armed, minimum battery voltage, peak current, charge used and optionally maximum relative altitude. It closes only on confirmed disarm and marks incomplete data rather than guessing. The summary is kept in memory and cleared when APMon reloads.
- Both views are reachable from the project menu on SW and COLOR in English and German. APMon remains read-only.

## Deutsch

- **Telemetrie-Diagnose** zeigt RC-Linkqualität, EdgeTX-Sensoren, FC-Statuspakete und die letzte FC-Textmeldung getrennt. Die Sensoransicht unterscheidet Live-Werte vom zuletzt gültigen Wert.
- **Letzte Armed-Phase** zeigt Armed-Zeit, niedrigste Akkuspannung, Spitzenstrom, Verbrauch und optional die maximale relative Höhe. Die Bilanz wird erst beim bestätigten Entarmen abgeschlossen und bei Lücken als unvollständig markiert. Beim Neuladen wird sie geleert.
- Beide Ansichten sind auf SW und COLOR auf Englisch und Deutsch über das Projektmenü erreichbar. APMon bleibt rein lesend.
