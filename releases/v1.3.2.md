# APMon v1.3.2 — Clearer Betaflight displays

## English

- COLOR hides the **Motors** row in Betaflight, matching the SW overview. The ArduPilot armed-state display is unchanged.
- COLOR labels the `GAlt` fallback **GPS altitude**. SW labels GPS speed with its unit, for example `GPS km/h`.
- The Betaflight setup check keeps **Basic readings available** as the main finding when only GPS confirmation is missing. Without a verified fix, GPS speed and `GAlt` remain `--` in the flight display. Reported values remain available in the sensor list.
- Betaflight dashboards and HUDs omit EKF. Diagnostics mark FC status and text as ArduPilot-only.

## Deutsch

- COLOR blendet die Zeile **Motoren** bei Betaflight aus, wie bereits die SW-Übersicht. Die Armed-Anzeige für ArduPilot bleibt unverändert.
- COLOR beschriftet den `GAlt`-Ersatz als **GPS-Höhe**. SW beschriftet das GPS-Tempo mit der Einheit, zum Beispiel `GPS km/h`.
- **Basiswerte vorhanden** bleibt der Hauptbefund im Betaflight-Einrichtungscheck, wenn nur die GPS-Bestätigung fehlt. Ohne bestätigten Fix zeigt die Fluganzeige für GPS-Tempo und `GAlt` jeweils `--`. Gemeldete Werte bleiben in der Sensorliste verfügbar.
- Betaflight-Übersicht und HUD blenden EKF aus. Die Diagnose kennzeichnet FC-Status und -Text als ArduPilot-spezifisch.
