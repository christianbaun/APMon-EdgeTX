# APMon v0.3.0 — Radio clock, FC message history and a compact project menu

## English

- **Radio clock:** The optional `HH:MM` display reads the EdgeTX radio clock, without a receiver connection and even if the calendar is unset. On SW it sits next to the page number; on COLOR it is larger and centered in the dashboard header. Toggle it in the project menu. SW saves the selection; on COLOR, **Widget settings → Clock** sets the persistent default.
- **FC message history:** Browse the latest **12 entries on SW** or **32 on COLOR**, newest first. Use the wheel, or tap on COLOR, to open a message with its full text, severity, age and consecutive repeat count. The history is cleared when APMon reloads.
- **Compact project menu:** The header now reads **APMon**, with a short description, GitHub address and the installed version below. Language, FC messages and the clock setting all fit on the same SW screen.
- **Hardware screenshots:** Both READMEs show v0.3.0 on the GX12, GX15 and TX16S MK3. APMon remains read-only and sends no commands to the flight controller.

Use **APMon-SW.zip** for GX12/Boxer or **APMon-COLOR.zip** for GX15/TX15/TX16S MK3. Back up any custom `config.lua` sensor mappings before updating.

## Deutsch

- **Senderuhr:** Die optionale `HH:MM`-Anzeige liest die EdgeTX-Uhr direkt aus dem Sender, auch ohne Empfängerverbindung und unabhängig vom Kalenderdatum. Auf SW steht sie neben der Seitennummer, auf COLOR größer und mittig in der Dashboard-Kopfzeile. Umschalten lässt sie sich im Projektmenü. SW speichert die Auswahl; auf COLOR legt **Widget-Einstellungen → Clock** den dauerhaften Standard fest.
- **FC-Meldungsverlauf:** Die letzten **12 Einträge auf SW** bzw. **32 auf COLOR** stehen als Liste bereit, neueste Meldung zuerst. Einträge lassen sich per Drehgeber oder auf COLOR per Touch öffnen. Die Detailansicht zeigt den vollständigen Text, Schweregrad, Alter und aufeinanderfolgende Wiederholungen. Beim Neuladen von APMon wird der Verlauf geleert.
- **Kompaktes Projektmenü:** In der Kopfzeile steht nur noch **APMon**. Darunter folgen Kurzbeschreibung, GitHub-Adresse und installierte Version. Sprache, FC-Meldungen und Uhr sind auf SW gleichzeitig sichtbar.
- **Echte Senderaufnahmen:** Beide READMEs zeigen v0.3.0 auf GX12, GX15 und TX16S MK3. APMon bleibt rein lesend und sendet keine Befehle an den Flugcontroller.

**APMon-SW.zip** ist für GX12/Boxer, **APMon-COLOR.zip** für GX15/TX15/TX16S MK3. Vor dem Update eigene Sensorzuordnungen aus `config.lua` sichern.
